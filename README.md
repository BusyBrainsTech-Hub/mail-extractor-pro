# Mail Extractor Pro

A Python-based email extraction and organization dashboard developed by BusyBrains Tech-Hub.

## Features

- Extract email addresses from supported local files.
- Remove duplicate email addresses within each source.
- Search extracted records.
- Filter records by email domain.
- Export records to CSV, TXT, and JSON.
- Store records in a local SQLite database.

## Supported Files

TXT, CSV, HTML, HTM, LOG, MD, and JSON files.

## Run Locally

Requires Python 3.

Run:

    python3 app.py

Then open:

    http://127.0.0.1:8765

## Important Note

This version extracts email addresses from uploaded local files. It does not crawl websites automatically.
